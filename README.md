# Grid Bot (PAPER)

Торговый grid-бот в режиме «бумажной» торговли: реальные цены с Bybit
(публичный API, ключи не нужны), виртуальный банк. Управление — через
Telegram-бота с телефона. Деплой — Railway.

## Как это работает

- Строится сетка ордеров вокруг текущей цены: N уровней вверх и вниз
  с шагом `STEP_PCT` (по умолчанию 1.2%).
- На каждом уровне — виртуальный ордер на сумму `QUOTE_PER_ORDER` USDT.
- Цена пробила уровень → ордер «исполняется» с учётом комиссии
  (`FEE_PCT`, 0.1%) и проскальзывания (`SLIPPAGE_PCT`, 0.05%).
- Продажа ищет парную покупку на соседнем уровне — это «цикл»,
  прибыль фиксируется. Если пары нет — это продажа инвентаря
  по себестоимости.
- Пробой сетки вверх → автоматическая перестройка от новой цены.
  Пробой вниз → держим базовую монету, ждём возврата (rebuild не делаем).
- **Банк переживает перезапуски** (с v3.1): балансы инициализируются один раз
  от `START_BALANCE` и дальше только растут/убывают от сделок. `Itog PnL`
  в статусе считается от первоначального эквити, а не от последнего запуска.
- Защита: дневной лимит просадки `DD_LIMIT_PCT` (5%) — стоп + уведомление.
- Фильтр тренда (v3.9, по умолчанию выкл): при падении сильнее порога
  (2%/6ч) покупки встают на паузу, продажи работают. Включается кнопкой
  в Nastrojki. Watchdog: при 5 ошибках подряд — уведомление.
- Ежедневный дайджест в Telegram (сделки, циклы, PnL, эквити) +
  автобэкап state.json и trades.csv файлами (с v3.4).

## Структура

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа, валидация env, авто-resume после рестарта |
| `config.py` | Настройки через переменные окружения |
| `paper_bot.py` | Ядро: сетка, исполнения, PnL, статистика, защита, банк между запусками (v3.1) |
| `telegram_bot.py` | Telegram-интерфейс (aiogram), кнопки, уведомления |
| `state_<SYM>.json` | Состояние пары — не коммитить (v3.5: имя с символом) |
| `trades_<SYM>.csv` | Журнал сделок пары (колонки kind/level с v3.7) |
| `equity_<SYM>.csv` | Почасовые снимки эквити — не коммитить |
| `AGENTS.md` | Инструкция для AI-агентов, которые ведут этот проект |
| `PROGRESS.md` | Текущее состояние работы, планы, история изменений |

## Деплой на Railway

1. Репозиторий подключён к Railway, запуск через `Procfile`
   (`worker: python main.py`).
2. **Обязательно подключить Volume** (иначе состояние сгорает при каждом
   рестарте/деплое):
   - Railway → сервис → Volumes → Add Volume, mount path: `/data`
   - Переменная окружения: `DATA_DIR=/data`
3. Переменные окружения:

| Переменная | Описание | По умолчанию |
|-----------|----------|--------------|
| `TELEGRAM_TOKEN` | Токен Telegram-бота (обязательно) | — |
| `ADMIN_ID` | Ваш numeric Telegram ID (обязательно) | — |
| `SYMBOL` | Торговая пара по умолчанию | `SOLUSDT` |
| `SYMBOLS` | Несколько пар через запятую (v3.5) | = SYMBOL |
| `POLL_SEC` | Период опроса цены, сек | `10` |
| `QUOTE_PER_ORDER` | Сумма на ордер, USDT | `10.0` |
| `STEP_PCT` | Шаг сетки, доля (0.012 = 1.2%) | `0.012` |
| `LEVELS_PER_SIDE` | Уровней с каждой стороны | `4` |
| `FEE_PCT` | Комиссия, доля | `0.001` |
| `SLIPPAGE_PCT` | Проскальзывание, доля | `0.0005` |
| `DD_LIMIT_PCT` | Дневной лимит просадки | `0.05` |
| `START_BALANCE` | Стартовый банк, USDT | `100.0` |
| `DATA_DIR` | Папка для state/log/trades | `.` (на Railway: `/data`) |

4. После деплоя бот стартует сам, если до рестарта был запущен
   (авто-resume, версия 3.0). Остановить — кнопка «Ostanovit»
   (тогда после рестарта сам не запустится).

## Управление в Telegram

Кнопки: **Zapustit setku** (запуск), **Ostanovit** (стоп), **Status**,
**Statistika**, **Logi** (скачать trades.csv и state.json), **Nastrojki**
(шаг сетки, сумма, уровни, интервал и т.д. — кнопками +/-),
**Grafik** (график эквити; снимки раз в час), **Para** (переключение
между парами при мультисимволе, v3.5). Файлы состояния — с именем
пары: `state_SOLUSDT.json` и т.д.

## Важно

- Это PAPER-торговля: реальных денег и API-ключей биржи нет.
- `state.json`, `trades.csv`, `bot.log` в репозиторий не коммитить
  (на Railway они живут на Volume).
